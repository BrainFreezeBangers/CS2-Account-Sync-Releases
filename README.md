# CS2 Account Sync

Überträgt deine CS2-Einstellungen (Fadenkreuz, Viewmodel, Sensi, Binds, HUD, Audio, Grafik, …) zwischen deinen
Steam-Accounts, Steam-Cloud-sicher und mit Rückgängig-Knopf.

## Installieren

1. Rechts unter **Releases** die neueste Version öffnen
   (oder direkt: [neueste Version](https://github.com/BrainFreezeBangers/CS2-Account-Sync-Releases/releases/latest)).
2. Die Datei **`CS2.Account.Sync_…_x64-setup.exe`** herunterladen und starten.
   Keine Adminrechte nötig.

> Windows zeigt eventuell „Der Computer wurde durch Windows geschützt“ an, weil die App nicht von einer bekannten
> Firma signiert ist. Dann auf **Weitere Informationen → Trotzdem ausführen** klicken.

## Updates

Musst du nicht selbst machen: Sobald es eine neue Version gibt, zeigt die App oben einen Hinweis an.
Ein Klick auf **Aktualisieren**, und die App startet kurz darauf in der neuen Version.
